
# Level wise Structure to build this project

Level 1 — Basic game
- Computer generates a random number between 1 and 100.
- Player enters a guess.
- Program tells them whether the secret number is higher or lower.
- Game ends when the player guesses correctly.




Level 2 — Limited attempts
- Give the player a fixed number of guesses.
- Track attempts remaining.
- Display a win or loss message.




Level 3 — Game features
- Easy, medium, and hard difficulty.
- Hints and a score system.
- Option to play another round.




Level 4 — Developer-quality code
- Reject letters, empty input, and out-of-range guesses without crashing.
- Split the game into functions.
- Add automated tests, refactor the code, and write a README.
- Publish the finished project on GitHub.
