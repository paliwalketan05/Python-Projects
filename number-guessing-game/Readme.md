# Number Guessing Game

A simple number guessing game built using Python. The computer generates a random number, and the player has to guess it within a limited number of attempts.

## Features

- Generates a random number for each game.
- Provides hints to help the player guess the number.
- Limits the number of attempts.
- Includes different difficulty levels.
- Displays the result when the player wins or runs out of attempts.

## Technologies Used

- Python 3
- Random module

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/paliwalketan05/Python-Projects.git
```

**2. Navigate to the project directory**

```bash
cd Python-Projects
```

**3. Run the game**

```bash
python main.py
```

Replace `main.py` with the actual filename of the game if it is different.

## How to Play

1. Run the Python file.
2. Select a difficulty level if prompted.
3. Enter your guess when asked.
4. Use the hints to figure out the correct number.
5. Try to guess the number before you run out of attempts.
